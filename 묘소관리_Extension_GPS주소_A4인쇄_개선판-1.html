새 묘소 기록

GPS 좌표로 주소를 조회합니다. 실제 묘소의 필지와 일치하는지 확인하세요. 산 지번은 카카오 REST API 조회 후에도 지적도에서 확인해야 합니다.
지번 자동조회 설정 (카카오 REST API 키)

카카오디벨로퍼스의 REST API 키가 있으면 해당 GPS 좌표의 지번 조회를 시도합니다. 키 없이도 참고 주소 조회를 시도하지만 산 지번을 보장하지 않습니다. 브라우저에 저장한 키는 노출될 수 있으므로 공개 배포에는 서버 중계가 안전합니다.

GPS 버튼을 누르면 좌표를 받고 주소를 자동 조회합니다. 좌표를 직접 입력한 경우에는 ‘현재 좌표로 지번 다시 조회’를 누르세요. 실제 지번은 필지 경계·GPS 오차에 따라 달라질 수 있습니다.
위치 버튼을 누르면 GPS 좌표와 주소를 확인합니다.
GPS는 HTTPS 웹주소에서 열어야 합니다. 태블릿 파일(content://)로 직접 열면 위치 권한이 차단될 수 있습니다.
